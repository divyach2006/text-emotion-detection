# text-emotion-detection
AI-based Text Emotion Detection web app built using Python, Flask, and Machine Learning. It predicts emotions from user input text using a trained ML model.
# Text Emotion Detection using Machine Learning

This project is a web-based Emotion Detection application that predicts human emotions from text input using Machine Learning.

The system takes user input text and classifies it into emotions such as:

- Happy
- Sad
- Angry
- Fear
- Love
- Surprise

---

## 🚀 Features

- Predict emotion from text input
- Simple and clean web interface
- Machine Learning model using Scikit-learn
- Flask-based web application
- Fast and accurate predictions

---

## 🧠 Technologies Used

- Python
- Flask
- HTML, CSS
- Scikit-learn
- Pandas
- Machine Learning
- TF-IDF Vectorizer
